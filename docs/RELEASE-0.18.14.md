# 0.18.14：没提醒时说得清原因

## 面板不再只给一个空结果

自动召回一直有回执，但面板没读它。现在面板按当前会话显示上一次自动提醒的结论：提醒了几条；没提醒时区分「没有匹配」「有相关但条件未确认」「有匹配但本轮条数用满」「记忆已关闭」「只在你问时检索」。

条件未确认原先会被算成「没有匹配」——因为自动召回只收完全适用的条目，只看默认召回分不清「没人提过」和「有人提过但条件没确认」。现在没命中时多发一次只看字面匹配的排序，把后一种，以及同主题两条规范互相冲突、还没定用哪条的，都报成 `needs_context`，并带上相关条数。注入给模型的文本一个字节都没变。

## 验证

- 面板头部显示「上次自动提醒 N 条」或对应的没提醒原因
- 条件未确认的候选不再误报成没有匹配，契约测试守住
- 回执只给结论和条数，不带原因码、内部编号或正文
