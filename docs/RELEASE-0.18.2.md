# dsh-lite-memory 0.18.2

自动召回和手动搜索对英文查询给同一个答案；对外说明改成能核对的事实。

## 英文整词判断统一

自动召回原来按包含判断匹配英文：查询 `git` 会命中标题 `Digital asset catalog`，因为 digital 里有 git。手动搜索早先已有整词检查，所以同一句话在两个入口给出相反结果——一边把不相关的卡片放进上下文，一边返回没有结果。

现在整词规则只有一份，放在 `view.js`，自动召回、手动搜索共用：查询不含中文时，英文词必须在标题、旧标题、标签、触发词、摘要或适用条件里按整词出现，否则不算相关。

回归样例进 `test/recall.test.mjs` A24：同一条记忆、同一个查询，自动注入不出现该标题，`store.search` 返回 0 条。

## 对外表述与实现对齐

- 包描述与 README 首段不再写「nothing in the system prompt」：实现的是一份不常驻的上下文槽，未命中的轮次不追加内容，命中时最多三张卡片（标题、编号、摘要、前提），受固定字节预算。
- `TRIGGERS.md` 里「从不进 system prompt」改成同样的口径，去掉两处互相矛盾的描述。
