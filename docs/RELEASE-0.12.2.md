# 0.12.2 · 收口读取与任务边界

- 新任务优先：用户明确换到无关任务时，旧栏目绑定立即撤销，旧规则不再自动注入；「继续改」「接着做」仍继承同一任务。
- 自由文本条件没有可信上下文时（如「发版当天」），自动注入、检索、读取都拿不到正文，只回状态。
- `memory_search` 只列当前任务真能用的条目，条件未知或不适用不出现在索引里，命中数与正文一致。
- `memory_read` 的条件门槛覆盖普通记忆，不再只拦学习产物；关联读取遇到失效源也不带出正文。
- 记忆范围没有候选或对不上时什么都不注入，不追问栏目；工具读取只回一句状态。
- 项目记忆关闭后，五个记忆工具对该会话不可见，执行入口也会拒绝；重新打开即恢复。
- 配置的项目根只覆盖自己的子树，不会把同级或上级目录并成同一个项目。
- 版本号升到 0.12.2；没有新增依赖、配色、圆角或阴影。

## 证据

- `npm test` 全绿：新增配置根子树隔离（S03）、新任务后 `decideRead` 只给索引不给规则。
- 新任务回归：口播任务后发送「帮我排查 PostgreSQL 连接超时」，锚点转为未绑定，旧规则不注入。
- 条件未知条目：搜索不命中，`memory_read` 返回 `needs_context` 且正文为空。
- `node --check index.js store.js state.js view.js client.js anchor.js learning.js bench/evolution.mjs test/scenario.test.mjs`；`ui-copy-lint`、`git diff --check`、impeccable 检测均无报错。
