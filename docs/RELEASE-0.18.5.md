# 0.18.5：内部编号退出所有文案

## 用户看到的变化

- 召回卡、搜索结果、实验规则、关联记忆都只给标题与适用范围，不再出现 `mem_…` 这类编号。
- 读正文、忘掉一条，改成按标题指名：`memory_read { title }`、`memory_forget { title }`。
  标题在项目层和全局层各查一次，重名时只报「有几条同名」，让模型先对齐标题而不是编编号。
- 更新一条记忆也用同一个标题重存：标题就是身份，改标题才是改身份。
- 相近提示、冲突提示、过期关联行同样只报标题。

- 面板内部请求继续用编号定位，编号不出现在任何界面字符串里。
- 数据格式、`state.json`、冷存文件不变，无需迁移。
