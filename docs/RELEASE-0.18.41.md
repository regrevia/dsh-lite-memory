# 0.18.41：把「从未读过」变成真话

## 问题

面板「结构体检」里的「从未读过」和筛选器按 `lastUsed` 是否为空判断。但 `lastUsed`
在新建、编辑时都会写入回退值，于是这个数字恒为 0，筛选也永远筛不出东西——一条从没被
召回过的记忆看起来像读过。

## 改法

- 记录新增 `everUsed`：只有真正送达模型并完成使用记账（`touchUsed`）才置真；
  第一次被用到时即使还在 `lastUsed` 的十分钟防抖窗口内，也只补标记、不额外落盘。
- 旧数据没有这个标记，用时间戳差异回填：`lastUsed` 与创建/更新时间都不同才算用过，
  因此升级后「从未读过」直接可信，不需要迁移脚本。
- 面板记录多带一个 `used` 布尔值；筛选项与体检计数都改看它，`lastUsed` 只继续用于
  陈旧度排序。界面文案不变。
- 没有新增常驻提示、没有改召回顺序、没有增加单次注入字节。

## 验证

- `test/recall.test.mjs`：新建条目 `used === false`；同一回合送达后变 `true`，
  且未送达的回合不变。
- `test/client.test.mjs`：带 `lastUsed` 回退值但 `used === false` 的条目仍计入
  「从未读过」，`used === true` 的排除。
- 全量 `npm test` 通过；三次基准 P50 67–69 ms，发生在系统负载 8.6 的机器上，
  与 0.18.40 的 48.6 ms 差异来自负载，上下文字节仍为 368 B。
