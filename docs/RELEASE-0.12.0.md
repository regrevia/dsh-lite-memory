# 0.12.0 · 记忆面板

- 会话头的大脑图标不再开小浮层，改为居中的记忆面板：默认看当前项目，也能切到其他项目和全局层；切过去只读，不回写、不迁移旧格式。
- 面板只用真实记忆数据：每条有效记忆一个图谱节点，共享标签和主题做枢纽，显式关联画实线；位置由 id 决定，同一批数据每次一样。旁边的计数、类型分布、规则和归档都来自当前层。
- 右侧按「记忆 / 规则 / 归档」列出条目，点开读当前正文；规则可撤回、固定、暂停、恢复、删除。
- 项目自进化的开关和用量收进左栏；只对当前项目可改，其他项目显示只读状态。
- `/lite-memory/overview` 与 `/lite-memory/body` 的读取路径改为只读：不迁移旧格式、不创建目录，避免打开面板就改磁盘。
- 没有新增依赖、配色、圆角或阴影；图谱是内联 SVG，沿用宿主 token。

## 证据

- `npm test` 全绿；`client.test.mjs` 11 项，含面板注册和图谱去重/确定性。
- `node --check` 覆盖 `index.js store.js client.js`；`ui-copy-lint` 无报错；`git diff --check` 干净；impeccable 检测 `client.js DESIGN.md` 无发现。
- 本地用 Chrome 无头渲染了当前项目、其他项目、规则、归档四个视图；真实页面点击仍受本机 Web 登录态限制，UI 验收只到 Node 渲染与接口契约。
- 没有预填性能或效果数字。
