# 0.18.50 — 图谱：不放大、不跳列表、悬停看全标题

## 改了什么

- 点标签/主题节点只做原地筛选：留在图谱页，不再切到列表，`#标签` 也不再写进搜索框，改成搜索框左边一个可点掉的 chip。
- 子图再小也不放大：图谱画布固定 640×472 布局坐标，之前按节点包围盒自适应，筛到两三个节点就撑满整屏。
- 悬停节点出完整标题气泡，跟随鼠标、按 300px 换行，不再只靠 SVG 里被截断的标签。

## 没改

- 点记忆节点仍然只在图里选中、右侧出正文，不跳列表。
- 缩放按钮、拖拽、重置缩放行为不变。

## 验证

- `node test/client.test.mjs` 22 passed + palace；`npm test` 全绿。
- `ui-copy-lint client.js` 3 error / 21 warning，与改动前同计数；`zh-lint` error 0。
