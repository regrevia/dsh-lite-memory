# 0.13.0

- 记忆的展示行标明归属：全局条目用 `[global]`，项目条目用项目目录名（如 `[DSH]`）。自动召回、检索、读取、保存和归档回执统一这个前缀；面板里的项目切换到全局仍显示「全局」。
- 项目名取当前工作目录的 basename，超过 16 字截断；项目条目不再和全局条目混在一列里分不出来。
- 记忆不再把版次当用户概念：面板、召回卡、检索/读取/保存回执和撤销冲突提示都只显示当前内容、归属与日期；内部修订号只用于并发校验和撤销，不展示。
- 保存口径收紧：单条正文上限 4096 → 1200 字节，并拒绝满是像素、字号、层级等实现参数的正文；工具说明要求先蒸馏，只写原则、判断规则和触发条件。
- 同一轮的引用行按条目去重；条目在轮内被读过又更新，也只占一行，内容取最新。
