# 0.18.3

修两处「不该自己扩大授权」的行为，其余行为不变。

## 从上一版恢复不再静默打开记忆

`state.json` 损坏或丢失时，`state.prev.json` 是关闭总开关之前的快照；原来直接采用它的 `control`，等于把用户关掉的记忆重新打开。现在两条恢复路径都写 `{ enabled:false, recoveryPending:true }`，恢复后保持关闭，等用户重新开启；面板与工具文案会说明「刚从损坏里恢复，需要你重新开启」，而不是让人以为是自己关的。

## 整理兜底不再把一句要求抬成全库规则

整理器返回空时，`pendingChangeFrom()` 原来硬写 `applicability: 'all_in_scope'`，于是「以后口播开头先给结论」这种没说范围的话会变成全项目规则。现在按文本与反馈线索判定：说到「所有 / 一律 / 默认 / 这个项目」才按全项目收；有 `taskKind` 就挂条件（`conditional`）；都没有就 `unresolved`，等确认。范围没定的条目即使已经生效，也会因为适用条件未确认而不进上下文。
