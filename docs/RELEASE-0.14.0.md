# 0.14.0

- 记忆页恢复关系图：搜索行右侧「列表 / 图谱」切换，图谱只替换列表区，右侧详情保留；点记忆节点看详情，点标签/主题节点转搜索。
- 面板说明收短：只留开关用途、状态和后果；「自进化」在记忆关闭时强制关闭并禁用，重开后仍保持关闭。
- 自进化 tab 只作用于当前项目，不提供范围选择；候选、试用、生效、暂停的计数缺失时显示未知，不补 0。
- 关闭项目记忆后，该项目的会话里记忆工具直接不可用；残留调用返回 `memory_disabled`，不落盘、不假装成功。管理面的采纳、修改、放弃、暂停、恢复、删除、撤销同样拒绝，面板只读，状态文件不变。
- 续接判断先认新对象：带「继续 / 这个」但换了对象时撤销旧范围；「继续改刚才那版脚本」这类明确续作仍保留范围。
