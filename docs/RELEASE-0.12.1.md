# 0.12.1 · 学习闭环与总开关

- 修掉三处会要求用户先选栏目的出口：没有已登记范围时不注入、不追问；有范围但问题对不上时整段跳过，按当前任务继续；工具绑定零命中或命中多条时只回一句读取状态，不再点名栏目。
- 未绑定索引只列和本轮问题有字面交集的记忆范围，最多三条；没有交集就什么也不给。
- 「本轮问题没有对上」等回执改成中性描述，不再把栏目选择当成用户义务。
- 项目记忆总开关接通：关掉后这个项目不再读写任何记忆，包括全局层；自动注入、检索、读取、引用、保存和建议全部停，面板只能查看，保留/拒绝/搬移/撤销返回 409。
- 关闭期间不能打开自进化，但可以把自进化关掉；重新打开项目记忆后，原来的自进化设置恢复。关一个项目不影响其他项目。
- 切换总开关立即作废旧请求上下文、进行中的整理和读取凭据；旧 `contextId` 不能继续带出关闭前的内容。
- 检索只靠「这个」「怎么」这类高频词重合不算命中；纯英文查询按整词匹配，`git` 不再命中 `digital`。
- 版本号升到 0.12.1；没有新增依赖、配色、圆角或阴影。
