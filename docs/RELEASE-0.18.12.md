# 0.18.12：点开更新过的记忆不再说「已删除」

## 按标题能读到正文

0.18.10 把引用行的可见句柄从编号换成标题，界面点开时只传标题、层和版本。
但引用文件里一直只存身份（`id`、层、位置），不存标题；服务端却拿请求里的标题去比
引用行上并不存在的 `title` 字段，于是每条引用点开都落进 `gone`。这一版先按当前索引
解析出标题再比，更新过的引用也能读到最新正文，版本对不上时仍回落到同一标题的现行条目。
点开时带上的层也参与筛选：全局和项目各有一条同名记忆时，点哪层读哪层，不按引用先后猜。

回归：`test/contract.test.mjs` 增加按标题打开引用的用例；引用已删、跨会话、跨目录
仍然只回 `gone`，不带正文。

## 会话里的引用行只标层

`约定 · 全局 · 你记的` 这类拼法把类型、层、来源挤在一行，最该看的层反而不显眼。
现在只留层标记：`[全局]`、`[项目]`，学习流程整理出来的再加 `[自进化]`。
类型（偏好、约定、流程……）仍存着，供检索和面板使用，不再上会话引用行。

## 两个刷新写法都能想起同一条规则

`dsh-unlag` 那条全局规则补了触发词 `Cmd+R`、`⌘R`、`刷新页面`、`热重载`。
用户打哪一种写法，都会命中同一条规则，不会再被当成「没说过这个快捷键」。

## 验证

`npm test` 全绿；客户端引用行断言覆盖 `[全局]`、`[项目]`、`[全局][自进化]`。
