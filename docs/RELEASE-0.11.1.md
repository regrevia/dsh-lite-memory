# 0.11.1 · 会话头与引用条

- 会话头的「自进化」文字按钮换成 14 px 大脑图标；开关状态仍由面板文字、图标透明度与 `aria-pressed` 表达。
- 移除「准备续聊摘要」。它只是把本轮更新列成可复制的 id、名字和版本，和「本轮更新」引用条重复；复制清单不带来新的读取或写入能力。
- 没有新增配色、圆角或阴影，图标使用 `currentColor`。

## 证据

- `npm test` 全绿；`ui-copy-lint` 无报错；`git diff --check` 干净。
- 图标是内联 SVG，不增加请求或依赖。
- 真实页面点击仍受本机 Web 登录态限制，UI 验收只到 Node 渲染与接口契约。
