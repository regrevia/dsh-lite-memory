# 0.18.48 — 面板上说人话：两个开关代替三个按钮

## 改了什么

- 记忆面板顶部的「自动提醒 / 仅搜索 / 关闭」三个按钮看不出哪个是当前状态，也看不出各自什么意思。改成两个开关：
  - **自动提醒**：开＝相关时自动放进这一轮；关＝只在你搜索时出现。
  - **启用记忆**：开＝正常参与；关＝已关闭，不提醒也不参与回答。
  面板里亮着的那个就是当前状态；写盘仍是原来的 `control` 接口（`adaptive` / `tool_only` / `off`），没有新增状态。
- 下方的冲突队列原来写「N 条保存没确认」，按钮叫「另存 / 忽略」：看不出是什么事。改成「N 条保存有冲突」＋一句「和已有记忆对不上，不处理就先不写进去」，按钮改为「存新的 / 丢掉」。行为不变：仍是人确认后才写，仍在同一把锁里消费待办。
- 两份文案都由纯函数 `modeSwitchesOf(mode)` 决定，测试直接断言三档（`adaptive`/`tool_only`/`off`）的开关与说明。
