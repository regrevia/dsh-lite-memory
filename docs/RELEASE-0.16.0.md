# 0.16.0

- 任务切换不再把上一条任务的规则带进新任务：带明确对象的新要求按新任务处理，只有「继续改」这类没有对象的短句才继承。
- 自进化关掉或换代后，已经准备好的实验正文和 `contextId` 立即失效；重新打开也不复活旧正文。
- 试用到期的学习结果不再自动注入，检索、读取、自动注入共用同一档可用性判断。
- 检索先过滤不可用条目再截断，不会被待确认的候选挤掉真正的命中；只有待确认候选时明确返回「适用条件还没确认」。
- 写入口径放宽：正文上限 4096 字节，整库 1 MB；摘要超长自动截断；不再因为正文提到像素、字号或写成指令句而拒绝保存。
- 只改标题的学习规则保持 `active` 和已有证据，不再降成试用。
- 容量腾挪不归档用户固定过的规则；实验规则与待确认候选的额度不再重复计数。
- 面板：作用范围改成「本项目内」，候选状态与引用分组的文案对齐实际行为，自进化开关标明会增加消耗。
