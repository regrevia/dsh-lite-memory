# 0.18.8：不再用「额度已用完」挡人

## 问题

自动召回把这一轮的记忆用量填满之后，任何一个 `memory_read` 都只回一行「本请求的记忆额度已用完」。
用户已经点名要读某条记忆，得到的却是一句没法处理的内部记账，且下一条消息之前完全没有出路。

## 改动

- 工具自己取的记忆单列一笔（6144 B / 单轮），自动注入用满不再连带挡住按标题读正文、查关联。
- 仍是硬上限：单轮正文 3 条、处理 8 次、字节封顶，越界照旧拒绝。
- 越界时说的是后果与下一步，不说「额度」：「这条消息已停止读记忆，下一条消息再读」。
- 面板自进化状态同改：「这轮先整理这些，下一条消息接着整理」。

## 回归

- 新增用例：自动注入占满 8192 B 之后，按标题读正文仍返回完整正文。
- `npm test` 全绿；`client.js` gzip 35000 B。
