# 0.18.45 — 宫殿房间按内容铺槽位

## 变化

- 房间预览槽位从固定 4 个改成 `min(4, max(1, 条数))`：1 条记录的房间只占 1 个槽，不再用 3 个虚位撑满一行。
- 空房间行为不变：仍然显示「还没有记录」，房间固定四间、位置不变。
- 新增纯函数 `palaceSlotCountOf`，槽位数量可单测，不依赖渲染。

## 为什么

ROADMAP R1 明写「房间宽高由内容决定，去掉无意义空地」。此前 1–3 条的房间会画 1–3 个 28% 透明度的虚线空槽，占 46px 高，读起来像没加载完。

## 验证

- `test/client.test.mjs`：新增槽位数断言（0/1/3/4/40 五个边界），22 项通过。
- `npm test`：21 个套件全绿；`node --check client.js` 通过；UI 文案 lint 与改动前同计数（3 错 21 警，均为既有误报）。
