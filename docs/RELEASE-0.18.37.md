# 0.18.37：npm 提醒先看当前项目层

- 动作前的 npm 提醒不再只查全局层：先查当前项目层的现行记忆，再查全局层，项目规则优先。
- 本机流程按记忆分层规矩留在项目层，也能在 `npm whoami` / `npm publish` 前拦一次，而不是因为没进全局层就失效。
- 同一条提醒仍然每轮最多一次，已交付过的条目不会再提示；项目记忆关闭时行为不变。
- 补回归：项目层与全局层各放一条 npm 规则，验证项目层优先且正文送达。

验证：`npm test` 全绿；`npm run bench` / `npm run bench:evolution` 均 exit 0；`style-lint` 通过。
