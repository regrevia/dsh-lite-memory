# 0.18.18：触发方式按项目选

- 面板把「启用记忆」换成一排选择：自动提醒 / 仅搜索 / 关闭。选「仅搜索」后不再主动弹卡片，工具检索照常；选「关闭」等同原来的总开关，写入与学习一起停。
- 触发方式存在项目自己的状态里，不改插件配置，也不影响其他项目；没有选过的项目仍跟随插件默认。改方式会换代次，关闭前排队的召回不会补交。
- 记忆开关和触发方式在同一把锁里落盘，不会只改一半；关闭时切换方式不会顺手把记忆打开。
- 编辑碰到别人先改过时，面板载入最新正文并说明「已载入最新内容，再保存会覆盖它」，不再只报一句通用失败。
- 引用点开时条目已归档或移走，改说「这条记忆已经不在这里了」，不再误称已删除。
