# 0.18.6：单字沾边不再触发召回

## 问题

「把这段视频的字幕导出来」会把「以后都用这个一次性脚本」召进上下文。原因是分词把整句切成单字，
`这` 出现在标题的 `这个` 里就算整词命中，一个词加一次分，三个单字把分数堆过阈值。

## 改动

- 汉字二元组在分词只有单字时补上，单字不再当整词。
- 整词命中改成「按字段取一次最大值」，同字段不再逐词累加。
- 匹配分只在真正有实质重合时才过阈值；`MATCH_FLOOR` 不变。

## 回归

- 新断言：`把这段视频的字幕导出来` 对那条记忆得分 0；真实相关句仍过阈值。
- `npm test` 全绿；恢复用例里原本被绕过的误触发句子。
- `client.js` gzip 34983 B。
