# 0.11.0 · 项目自进化〔实验〕

这是一版实验功能，默认关闭。它不改变普通记忆的写入、检索和引用条。

## 能用什么

- 在会话头打开「项目自进化〔实验〕」，只对当前项目生效。
- 纠正会整理成少量带适用范围的项目规范；明确说「以后都这样」才直接生效，否则先试用。
- 认可作品只给已有规范附一条样例（版本 + 维度，未验证）；执行漏掉只补一条检查点，不会变成同义禁令。
- 「再做一期」在唯一可信的延续关系下读取当前正文；没有锚点先给不超过三个栏目。
- 面板显示试用/生效、来源、最近变更、检查点与样例数，可撤回、固定、暂停、恢复、删除。
- 关闭后停止学习、读取和晚到写入；已固定为普通项目规范的内容继续生效。

## 边界

- 一次整理最多 2 处改动、768 输出 token、15 秒，输入 ≤ 8 KiB；同一作品 ≤ 2 次，同一项目 24 小时 ≤ 6 次。
- 规则 32、待定 12、每规则样例 4/检查点 3/来源 3/旧版本 2；到顶暂停新学习，不静默丢已生效规则。
- 关闭、切作品、换状态、超时或版本变化都会让晚到的整理整批作废。
- 整理用的模型调用不含工具、子代理和完整历史；输出不是合法 JSON 就整批拒绝，不做第二次修复。
- 用量缺失显示「未知」，不补零；整理调用与单请求记忆载荷分开显示。

## 证据

- `npm test`：含 `learning.test.mjs` 36 项、`scenario.test.mjs` 4 项（口播/剪辑/字幕 + 新会话对照）、`contract.test.mjs` 真实宿主整理流程。
- `npm run bench:evolution`：32 条规则、64 条回执下整理输入 2.7 KB、状态 123 KB、热快照 P50/P95 1.1/1.3 ms，超限非零退出。
- 真实页面点击仍受本机 Web 登录态限制；UI 验收只到 Node 渲染与接口契约，不冒充页面验收。
- 模型侧质量、重复纠正率、首版认可率没有预填数字，等真实模型样本后再报告。
