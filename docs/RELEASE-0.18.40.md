# 0.18.40

## 更新句柄也能拿到相近完整标题

`memory_save` 用 `updateTitle` 改一条记忆时，如果传的是缩短过的标题，以前只回「没有这条记忆」；现在和 `memory_read` / `memory_search` 一致，在报错里列出最多 3 条相近的完整标题，模型可以一次改对。

- 只影响失败路径：成功写入的流程、工具描述和常驻字节不变（13375 字节）。
- 不会模糊读取或模糊改写：仍要求完整标题或 id。
- 回归：`test/contract.test.mjs` 断言缩短标题的更新请求报出完整标题，且不出现 `undefined`。

## 使用记账回归

`test/recall.test.mjs` 新增用例：没有送达模型的回合结束后，条目的 `lastUsed` 不变；真正送达到卡片的回合收尾时才回写。防止以后改动把「检索过」误记为「用过」。
