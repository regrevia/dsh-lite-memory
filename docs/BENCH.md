# 证据 / Evidence

本地、可重跑。测试命令与数字都来自这台机器，不是估算。

## 跑法

```bash
npm test          # 存储、状态、投影、召回、跨层、客户端投影、接口契约
npm run bench     # 固定数据集上的准备时延与长期序列
npm run bench:evolution  # 实验规则/样例/检查点/回执的存储与投影成本
```

## 本轮门禁（U01–U06）

| 编号 | 场景 | 现状 | 证据 |
| --- | --- | --- | --- |
| U01 | 两轮读同一 ID，组件折叠/重挂载 | 引用按每轮自己的工具结果重建，不读全局面板状态 | `client.test.mjs`：`citationsOfTurn` 只从节点取；同一轮去重 |
| U02 | PTC 子结果与普通结果 | 子调用与主结果同一套元数据解析；canonical 值不带维护字段 | `client.test.mjs` 子调用断言；`contract.test.mjs` 元数据键集合 |
| U03 | 旧行、noop、needs_resolution | 没有元数据只读；`changed !== true` 不出现撤销；旧版本撤销返回 409 | `client.test.mjs`；`contract.test.mjs` 过期撤销 |
| U04 | keep/undo 网络失败后重试 | keep 的 `operationId` 存在组件 ref 里，重试复用；undo 按 id + 版本重试 | 代码路径；未做真实断网点击 |
| U05 | 收起/切轮后旧正文迟到 | 每次请求带代次，切换、收起、卸载都作废旧响应 | 代码路径；未做真实页面点击 |
| U06 | 引用已更新/删除/移动 | 正文按 id 现查当前层：版本、标题、归档状态现取；找不到显示已删除 | `contract.test.mjs`（当前版本、`scopeLabel`、`gone`）；`memory_read` 归档可读已实测 |

真实页面点击需要已登录的 Web 视图；本次环境拿不到该视图的登录态，所以 U04/U05 只到代码路径与逻辑单测，没有冒充成页面验收。

## 固定数据集性能

2026-10-29，macOS arm64，Node v24.16.0，本地 SSD。数据：项目 200 条 + 全局 200 条，全部带标题、摘要、`when`、正文；另加一条正面场景，确认全局卡片真的进得来且不超预算。0.18.38 版含跨层搬移后的复测。

0.18.0 起每次保存都走「写临时文件 → fsync → rename → fsync 目录」并保留上一版，代价是单次保存多两次落盘；下面这组数是带这套持久化保证后测的。

| 指标 | 数值 |
| --- | --- |
| 准备时延 P50 | 51.4 ms |
| 准备时延 P95 | 59.4 ms |
| 冷启动首次准备 | 76.5 ms |
| 最慢一次 | 76.5 ms |
| 每次准备上下文 | 368 B |
| 正面场景上下文 | 335 B，含 1 张全局卡片，未超 3 条 / 1200 字节 |
| 每次准备文件读取 | 0.2 |
| 本次数据规模 | 项目 200 条 + 全局 200 条 |

数据翻倍到两层各 200 条后仍在 deadline 150 ms 内：0.18.38 复测 P95 59.4 ms。模型 provider 在准备阶段无 I/O、无网络。

## 实验整理成本（0.11.0）

固定 32 条实验规则、64 条回执，全部带 4 个样例、3 个检查点、3 条来源。macOS arm64，Node v24.16.0，本地 SSD：

| 指标 | 数值 |
| --- | --- |
| 规则数 / 整理输入规则数 | 32 / 6 |
| 整理输入字节 | 2,719 B（上限 8,192 B） |
| `state.json` | 123 KB（上限 256 KiB） |
| 样例 / 检查点 / 来源深度 | 4 / 3 / 3 |
| 效果回执窗口 | 64（已知 usage 16 次） |
| 单条 `memory_read` 投影 | 256 B |
| 冷启动快照 | 1.9 ms |
| 热快照 P50 / P95 | 1.1 / 1.3 ms |

`npm run bench:evolution` 会在达到任一上限时以非零码退出，可当门禁用。

## 效果评测

§17.4 的 2×2 防污染实验要跑真实模型、固定评分，不在 CI 里，也没有预填改善百分比。`test/scenario.test.mjs` 与 `bench/evolution.mjs` 只证明场景边界、读取条件和成本上限；不声称模型更聪明。GitHub 上的功能主张只对应这些确定性测试和本地性能数字，模型侧效果等实跑后再写。
