# 证据 / Evidence

本地、可重跑。测试命令与数字都来自这台机器，不是估算。

## 跑法

```bash
npm test          # 存储、状态、投影、召回、跨层、客户端投影、接口契约
npm run bench     # 固定数据集上的准备时延与长期序列
```

## 本轮门禁（U01–U06）

| 编号 | 场景 | 现状 | 证据 |
| --- | --- | --- | --- |
| U01 | 两轮读同一 ID，组件折叠/重挂载 | 引用按每轮自己的工具结果重建，不读全局面板状态 | `client.test.mjs`：`citationsOfTurn` 只从节点取；同一轮去重 |
| U02 | PTC 子结果与普通结果 | 子调用与主结果同一套元数据解析；canonical 值不带维护字段 | `client.test.mjs` 子调用断言；`contract.test.mjs` 元数据键集合 |
| U03 | 旧行、noop、needs_resolution | 没有元数据只读；`changed !== true` 不出现撤销；旧版本撤销返回 409 | `client.test.mjs`；`contract.test.mjs` 过期撤销 |
| U04 | keep/undo 网络失败后重试 | keep 的 `operationId` 存在组件 ref 里，重试复用；undo 按 id + 版本重试 | 代码路径；未做真实断网点击 |
| U05 | 收起/切轮后旧正文迟到 | 每次请求带代次，切换、收起、卸载都作废旧响应 | 代码路径；未做真实页面点击 |
| U06 | 引用已更新/删除/移动 | 正文按 id 现查当前层：版本、标题、归档状态现取；找不到显示已删除 | `contract.test.mjs`（当前版本、`scopeLabel`、`gone`）；`memory_read` 归档可读已实测 |

真实页面点击需要已登录的 Web 视图；本次环境拿不到该视图的登录态，所以 U04/U05 只到代码路径与逻辑单测，没有冒充成页面验收。
