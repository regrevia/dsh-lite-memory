# 0.17.0

- 新增记忆宫殿视图：四条固定房间（习惯与规范 / 方法与经验 / 资料与入口 / 其他记录），空房间保留位置，每页 24 个槽位，点展品交给现有详情入口；同一时刻只展开一间，再点收起，减少动态时不做动画。
- L1 建议行的按钮从 `keep` 改为「保留」，写完直接消失、行变成 `memory · kept`；仍然是同源直写，不产生消息、不动输入框。
- `state.json` 读不出来时不再让整层不可用：原始字节先隔离成 `state.corrupt-<时间>.json` 副本再重建，同内容副本只留一份，写不进副本才报失败。
- 锁文件按 pid 判活并回收：`EPERM` 视为「进程存在但不属于当前用户」，绝不回收；遗留的死锁不再需要人工删。
- 落盘统一走「写临时文件 + fsync + rename」，机器掉电不会留下半截索引。
- TRIGGERS.md 与 README 对齐当前实现，新增 `docs/CONVENTIONS.md`（写的是代码真正执行的判定规则）。
