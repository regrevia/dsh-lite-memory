# 0.18.38：面板可跨层搬移记忆

- 明细里新增搬移动作：项目记忆可移到全局，全局记忆可移回当前项目；全局视图只读，搬回由当前会话的项目层承接。
- 同一操作重复提交按 `operationId` 幂等；目标层有同名、近义或主题槽位冲突时拒绝并说明原因，不覆盖。
- 服务端只认会话身份：面板带 `sessionId`，项目目录由服务端查，客户端不用抄路径；未知会话回 `请求不完整`。
- 搬移后 id 换成新层身份，旧 id 留原层归档；出链在目标层不可见时拒绝，避免搬过去就断链。
- 补回归：保存探针、移到全局、再移回项目，校验层、id、正文与旧 id 归档读取。

验证：`npm test` 全绿；`npm run bench` exit 0（P50 51.4 ms / P95 59.4 ms，上下文 368 B）；`style-lint` 通过。
