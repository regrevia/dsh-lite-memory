一轮里读了两次、两次都被同一条适用条件拦下时，聊天会显示两行一模一样的提示。这次只修这个。

## 重复行只留一行

拦截结果不返回编号和标题（`id` 为空），两次读的载荷因此逐字节相同，按编号去重认不出来。现在 `client.js` 按「曝光类型 + 文案 + 正文」认身份：同一轮里同键只显示第一次出现的那行，其余行留在 DOM 里但隐藏。不加计数、不写「共 N 条」，也不打印任何内部编号。

文案相同但来源不同（`memory_search` 与 `memory_read` 恰好说同一句话）不合并；只有一条时不受影响。
